# Claude Certified Architect — Professional: Domain Study Guides

Seven GitHub-ready markdown guides covering all domains of the Claude Certified Architect Professional exam, expanded beyond the cram-sheet level with industry best practices, worked architecture diagrams, a running telecom example, and citations to primary sources (Anthropic engineering blog, official docs, NIST, GDPR, HIPAA, FedRAMP, Google SRE).

## How to use this set

- Each file follows the same shape: core concepts → worked examples → an architecture diagram → key takeaways → references.
- A single running example — a telecom network fault-triage agent — threads through all seven files, showing how the same system looks from the design (1), prompting (2), integration (3), eval (4), governance (5), lifecycle (6), and operational (7) lens.
- References at the bottom of each file link to primary sources (Anthropic's own engineering blog and docs, official regulatory text, and standards bodies) rather than secondary summaries, so claims can be verified directly.

## Exam format (for context)

63 scenario-based questions, 120 minutes, 720/1000 to pass, proctored via Pearson VUE.
